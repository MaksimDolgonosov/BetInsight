# BetInsight

Сервис публичных AI-прогнозов на спортивные события. Он проверяет на реальных коэффициентах, даёт ли анализ букмекерской линии положительный результат, и показывает статистику, которую нельзя изменить задним числом.

Прогнозы не являются ставками и не отправляются букмекерам. Сервис только публикует информационный прогноз до начала события и затем считает, сбылся ли он.

Подробные требования — в [техническом задании](TZ_BetInsight.md).

## Что делает этап 1

- Забирает коэффициенты из [The Odds API](https://the-odds-api.com/) по четырём турнирам: Ла Лига, Бундеслига, Лига чемпионов УЕФА и Евролига. Рынки — исход матча и тотал.
- Сначала считает консенсус-вероятность и value математической моделью, затем проверяет кандидата через LLM в [OpenRouter](https://openrouter.ai/).
- Публикует прогноз на сайте и в Telegram до начала события. После события автоматически считает результат.
- Показывает честную статистику: hit rate, ROI, кривую банка, калибровку и сравнение с бейзлайнами.
- Интерфейс на русском и английском: `/ru` и `/en`.

На этапе 1 нет приёма ставок, платежей, личного кабинета и мобильного приложения. Платный доступ заложен только как следующий этап.

## Стек

Next.js (App Router), TypeScript, next-intl, Tailwind CSS и shadcn/ui, PostgreSQL в Neon через Drizzle, Upstash QStash и Redis, Telegram-бот на grammY, OpenRouter, Auth.js, Sentry. Хостинг — Vercel.

## Локальный запуск

```bash
npm install
cp .env.example .env
npm run dev
```

Сайт открывается на [http://localhost:3000](http://localhost:3000). Секреты из `.env` в репозиторий не коммитятся: в git попадает только `.env.example`.
